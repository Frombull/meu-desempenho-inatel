# Meu Desempenho (protótipo para o App Inatel)

Protótipo interativo da nova funcionalidade **Meu Desempenho**: simulador de notas e frequência para o App Inatel.
Projeto final da disciplina Interface Homem-Máquina (Engenharia de Software, Inatel), de Marco Di Toro.

**Projeto acadêmico, sem vínculo oficial com o Inatel.** Os dados do aluno e das disciplinas são fictícios, e as regras de média
(NP1 35%, NP2 35%, laboratórios 30%, aprovação com 60, frequência mínima de 75%) são premissas do projeto.

Publicado em: https://frombull.github.io/meu-desempenho-inatel/

## Como usar

Abra o link. Em telas largas aparece um roteiro de teste ao lado do celular; no celular, o app ocupa a tela toda.
Atalhos: `#/notas`, `#/desempenho` e `#/simulador/M210`.

HTML, CSS e JavaScript puros, mais [Chart.js](https://www.chartjs.org/) (em `vendor/`). Não precisa de build.
O modelo de domínio (`js/model.js`) segue o diagrama de classes do projeto.
